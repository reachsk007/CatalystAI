# Security

The canonical source is `https://github.com/reachsk007/CatalystAI`. Treat forks,
look-alike domains, unsolicited messages, and guaranteed-return claims as
unaffiliated unless this repository explicitly says otherwise.

Maintainers will never ask for brokerage credentials, seed phrases, API secrets,
remote-desktop access, or payment to unlock a trading signal. Do not paste secrets
into issues, pull requests, Pine inputs, screenshots, or logs.

- Review links and downloads before opening or running them.
- Install only from documented project configuration; never run commands copied
  from unsolicited comments or messages.
- Keep broker and data credentials in local environment variables or a secret
  manager. Current tests require no credentials.
- Alerts and backtests are not identity verification, investment advice, or a
  guarantee of performance.

Report impersonation through GitHub's abuse tools. Do not disclose sensitive
vulnerability details publicly; enable private reporting first.
