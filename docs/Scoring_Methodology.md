# Scoring Methodology

This document will define every factor, transformation, weight, interaction, penalty, confidence adjustment, and missing-data rule.

## Required standard

Each score must include:

- a precise definition,
- source fields and observation dates,
- normalization and bounds,
- update frequency,
- confidence and missing-data treatment,
- an explanation suitable for human review,
- tests covering boundary and failure cases, and
- point-in-time backtest requirements.

Weights are provisional until validated. Correlated inputs must not receive multiple independent rewards for the same underlying evidence.
